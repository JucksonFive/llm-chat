## Image Guidelines

When adding screenshots:

1. **Resolution**: 1920x1080 or higher for clarity
2. **Format**: PNG for UI screenshots (better quality than JPEG)
3. **Theme**: Show both dark and light themes where applicable
4. **Content**: Use realistic but safe/example data (no real API keys, personal info)
5. **Annotations**: Add arrows or highlights if needed to draw attention to features
6. **File size**: Compress images to keep repo size manageable (<500KB per image)
7. **Naming**: Use kebab-case matching the filenames referenced in README.md

## Tools for Screenshots

- **macOS**: Cmd+Shift+4, then drag to select area
- **Windows**: Win+Shift+S for Snipping Tool
- **Linux**: Screenshot tool or `gnome-screenshot -a`
- **Browser DevTools**: Responsive mode for testing different screen sizes
